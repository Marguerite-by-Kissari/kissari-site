# 03 — Éléments d’interface : landing desktop

## Périmètre

- Header desktop et zones graphiques statiques de la landing.
- Aucune interaction produit supplémentaire, aucun conseil éditorial, aucun flux newsletter/blog/contact.

## Header desktop

- Fond noir ; hauteur cible 115 px.
- Logo blanc : `Livrables/Header/Logo blanc KISSARI.png`, position gauche, plan `z-index: 10`.
- Navigation visible telle que fournie dans la maquette ; chaque entrée est un lien actif qui renvoie temporairement vers la landing page (`/`) en attendant les pages internes.
- Aucun menu burger ni comportement responsive n’est défini avant le lot tablette/mobile.

## Hero, manifeste et expertises

- Les éléments sont placés selon les calques et espaces décrits dans `01-homepage.md`.
- Les personnages, pictogrammes, fonds et frise sont visuels statiques ; leurs chemins sont ceux du vault listés dans `01-homepage.md`.
- Les quatre cartes expertises sont non cliquables ; elles n’exposent aucun CTA ni `En savoir plus`.

## Compatibilité W3C

Les éventuels constats W3C seront formulés comme propositions séparées. Ce document ne demande aucune correction automatique de structure, de sémantique ou d’accessibilité.
