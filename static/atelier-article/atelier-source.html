      02 · Flux éditorial

      Construire le fil du texte

      Sélectionnez un mot ou une portion de phrase, puis cliquez sur G — Gras près du champ. Recliquez avec la sélection pour retirer le gras. Les doubles astérisques restent visibles dans le champ, mais pas dans l’aperçu.

      Pour annoter un passage, sélectionnez-le puis cliquez sur * — Note à côté de Gras. Saisissez la note dans la fenêtre et enregistrez : le renvoi est attaché au passage, la note apparaît en bas d’article. Sélectionnez son marqueur pour la modifier.

      Ajoutez les blocs dans l’ordre de lecture. Les cadres sont des blocs, pas des problèmes de mise en page.
